## **Trabajo Práctico Final**

## **Visualización de Datos utilizando la World Bank Data360**

1. Explorar la [API de datos del Banco Mundial](https://data360.worldbank.org/en/api) para identificar bases de datos e indicadores disponibles.  
   * Qué bases de datos existen.  
   * Qué indicadores están disponibles.  
   * Cómo se estructuran (país, tiempo, temática, etc.)

2. Desarrollar hasta **3 visualizaciones (preferentemente interactivas)** sobre un tema relevante, aptas para ser utilizadas en una nota o artículo periodístico.  
   Implementar las visualizaciones utilizando alguna de las siguientes herramientas:

**Colab** (Python o R)  
		Python: *pandas/polars, duckdb, altair, etc.*  
		R: *tidyverse, ggplot2, dplyr, etc.*  
	**Observable** (Plot, d3.js, Vega-Lite)

👥 Trabajo grupal: grupos de 3 integrantes  
📅 Fecha de entrega: **lunes 30/11/2026 – 00:00**
